01 / The question

What can a response become?

Verity studies a classification problem using text statistics and simulated physiological variables. The interesting engineering challenge is the journey: converting raw responses into features, comparing models and presenting their outputs in an understandable interface.

The experiment contains 100 hotel reviews and 50 interrogation-style responses, with 75 examples in each class. It is a small educational dataset designed to explore the workflow.

Experimental by design. Verity is not a validated lie detector. Its physiological training signals are synthetic, and the results do not establish real-world deception detection.

01

Turn a sentence into measurable features.

The extractor produces numeric descriptions of text before any classifier is trained: length, vocabulary indicators and repetition.

python/verity.py · extract_text_featuresPYTHON ↓
ORIGINAL SOURCE EXCERPT
def extract_text_features(text):
    tl = text.lower()
    words = tl.split()
    sentences = [s.strip() for s in re.split(r'[.!?]+', text) if s.strip()]
    n_words = len(words)

    hedge_count = sum(1 for h in HEDGES if h in tl)
    intens_count = sum(1 for i in INTENSIFIERS if i in tl)
    denial_count = sum(1 for d in DENIALS if d in tl)
    dist_count = sum(1 for d in DISTANCERS if d in tl)
    fp_count = tl.count(" i ") + tl.count("i ") + tl.count(" my ") + tl.count(" me ")
    pos = sum(
        1
        for w in [
            "great",
            "good",
            "excellent",
            "nice",
            "wonderful",
            "clean",
            "comfortable",
            "friendly",
            "helpful",
            "fine",
            "okay",
            "alright",
        ]
        if w in tl
    )
    neg = sum(
        1
        for w in [
            "bad",
            "poor",
            "terrible",
            "awful",
            "dirty",
            "rude",
            "noisy",
            "disappointing",
            "wrong",
            "problem",
            "issue",
        ]
        if w in tl
    )

    return {
        "n_words": n_words,
        "n_sentences": max(len(sentences), 1),
        "avg_word_len": round(float(np.mean([len(w) for w in words])) if words else 0, 3),
        "avg_sentence_len": round(n_words / max(len(sentences), 1), 3),
        "hedge_count": hedge_count,
        "hedge_ratio": round(hedge_count / n_words if n_words else 0, 4),
        "denial_count": denial_count,
        "denial_ratio": round(denial_count / n_words if n_words else 0, 4),
        "distancing_ratio": round(dist_count / n_words if n_words else 0, 4),
        "first_person_ratio": round(fp_count / n_words if n_words else 0, 4),
        "n_questions": text.count('?'),
        "n_exclamations": text.count('!'),
        "repetition_ratio": round(1 - (len(set(words)) / len(words)) if words else 0, 4),
        "specificity_score": round(max(0, (hedge_count - intens_count + 3) / 6), 4),
        "sentiment_ratio": round((pos - neg) / (pos + neg + 1), 4),
    }
  1. Lowercase and split the text into words, then identify non-empty sentence segments.
  2. Count the presence of each lexicon phrase. Repeating the same hedge twice still contributes one matching phrase.
  3. Return a feature dictionary. Repetition compares unique whitespace tokens with the total; punctuation remains attached to words.
ILLUSTRATIVE WALKTHROUGH
Text: "I think the room was clean. I think the staff were helpful."
Words: 12    Sentences: 2    Unique word tokens: 9
Hedge indicators: 1 (the phrase "i think")
Repetition ratio: 1 − 9 / 12 = 0.25
These numbers describe the text; they do not establish truthfulness.
02

Keep scaling tied to the training split.

The experiment divides the feature matrix into training and test rows, then learns the scaling parameters from the training rows.

python/verity.py · split & scalingPYTHON ↓
ORIGINAL SOURCE EXCERPT
X = df[FEATURE_COLS].values
y = df["label"].values
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, stratify=y, random_state=42
)
scaler = StandardScaler()
X_train_sc = scaler.fit_transform(X_train)
X_test_sc = scaler.transform(X_test)
  1. Separate 23 input columns from the class labels. stratify=y preserves class balance as closely as the split size permits.
  2. Fit StandardScaler on the training subset, learning one mean and scale per feature.
  3. Transform test rows with the same parameters. Earlier outlier clipping still uses the full dataset and should move inside the training pipeline.
ILLUSTRATIVE WALKTHROUGH
Input matrix: 150 examples × 23 features
75/25 split:  112 training rows + 38 test rows
Illustrative scaling: training mean 10, scale 2, test value 14
Transformed test value: (14 − 10) / 2 = 2
03

Compare three learning approaches.

The same split feeds three classifiers. The forest uses unscaled features; logistic regression and SVM use the scaled versions.

python/verity.py · classifier trainingPYTHON ↓
ORIGINAL SOURCE EXCERPT
rf = RandomForestClassifier(n_estimators=200, random_state=42, min_samples_leaf=2)
lr = LogisticRegression(max_iter=500, random_state=42)
svm = SVC(probability=True, random_state=42)
rf.fit(X_train, y_train)
lr.fit(X_train_sc, y_train)
svm.fit(X_train_sc, y_train)
  1. Random Forest combines 200 trees, with at least two samples per leaf.
  2. Logistic Regression fits a linear decision model, with a maximum of 500 iterations.
  3. SVC fits a support-vector classifier and enables probability estimation. These calls train models; they do not deploy them in the browser.

05

Choose different questions across three turns.

The cockpit uses a Fisher–Yates shuffle to create an index order when the category changes. Each turn reads the next index from that order.

web/cockpit.jsx · scenario selectionREACT / JSX ↓
ORIGINAL SOURCE EXCERPT
const scenarioOrder = useMemo(() => {
  const pool = window.VERITY_SCENARIOS[category];
  const idxs = pool.map((_, i) => i);
  // Fisher–Yates
  for (let i = idxs.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [idxs[i], idxs[j]] = [idxs[j], idxs[i]];
  }
  return idxs;
}, [category]);

const scenario =
  window.VERITY_SCENARIOS[category][scenarioOrder[(turn - 1) % scenarioOrder.length]];
  1. Create one index for each prompt in the selected category.
  2. Shuffle the indices with pairwise swaps; the scenario data itself is unchanged.
  3. Use the turn number to select a prompt. Six categories and at least five prompts per category support the three-turn session.

Illustrative shuffled order: [3, 0, 4, 1, 5, 2]
Turn 1 → prompt 3
Turn 2 → prompt 0
Turn 3 → prompt 4
Actual order varies each time the category is selected.

05 / What comes next

A better experiment starts with better evaluation.

The next iteration should isolate preprocessing inside each training fold, add a text-only baseline and evaluate on independent data. Because the simulated physiological variables are generated from class labels, strong scores can reflect the construction of the dataset itself.

The original report and slides capture different revisions. The technical details here follow the Python implementation, with evaluation boundaries documented in the README.
